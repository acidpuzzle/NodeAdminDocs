Локация
=======

*Локация* — это физическая или логическая сущность, которая занимает определенное место в иерархическом дереве.

Пример иерархии:

.. code-block:: text

   Root -> Проект -> Организация -> Офис -> Этаж -> Помещение -> Стойка

Каждый элемент в этой цепочке (проект, организация, офис, этаж, помещение, стойка) является локацией.

Область видимости локации определяется её положением в дереве и подчиняется двум правилам:

1. **Нисходящая полная видимость:** Любой узел дерева имеет доступ ко всем сущностям, находящимся ниже него в его поддереве.
2. **Восходящая контекстная видимость:** Любой узел видит всю цепочку своих родительских узлов вплоть до корня (Root), наследуя их контекст.
